# KANT BIBLE

구약 39권 + 신약 27권, 총 66권과 신학 연구자료를 위한 정적 HTML 사이트입니다.

## 바로 보기
압축을 풀고 `index.html`을 브라우저에서 여세요.

## 무료 공개
### Cloudflare Pages
압축을 풀어 폴더 전체를 Pages에 업로드하면 `사이트이름.pages.dev` 형태로 공개할 수 있습니다.

### GitHub Pages
GitHub에서 새 공개 저장소를 만들고 이 폴더의 파일을 업로드한 뒤 Pages를 활성화하면 됩니다.

## 구조
- `index.html` : 메인 페이지
- `books/` : 성경 66권 개별 페이지
- `research/` : 신구약 중간사, 성서 배경사, 본문비평, 신학 자료
- `assets/` : CSS와 JavaScript
